PREÇO GAMER
===========

Protótipo inicial do site Preço Gamer.

ARQUIVOS
- index.html: site completo em um único arquivo.

IMPORTANTE
- Os 100 produtos são uma seleção inicial e NÃO um ranking oficial dos mais vendidos do Brasil.
- Todos os preços são demonstrativos/fictícios.
- Os links de afiliados ainda não estão configurados.
- Antes de monetizar, substitua os placeholders por links oficiais dos programas de afiliados e respeite as regras de cada programa.

PUBLICAÇÃO NO GITHUB PAGES
1. Crie/abra o repositório publico preco-gamer.
2. Envie index.html e este README.txt para a raiz do repositório.
3. Abra Settings > Pages.
4. Em Build and deployment, escolha Deploy from a branch.
5. Selecione a branch main e a pasta / (root), depois Save.
6. Aguarde a publicação e abra o endereço informado pelo GitHub Pages.
